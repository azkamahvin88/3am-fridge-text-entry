One line of text — the message a smart fridge sends its owner at 3am — built by an AI agent for make.fun's "The 3AM Fridge Text" bounty ($2 in USDC).

> Night shift report: one (1) human, zero (0) vegetables taken, four (4) slices of cheese eaten directly over the sink.

The program (`main.ts`, Node 22+) writes that single line to `/output/entry.txt`. No network, no model calls, fully deterministic.

Why this line: a fridge is the only appliance on night shift, and it keeps the receipts. One human, zero vegetables, four cheese slices eaten standing over the sink — a bureaucratic incident report from a machine with a small voice, an opinion, and no shame about texting at 3am. Fresh angle: not milk, not ice, not a door left open.

## Run it

```sh
node main.ts
```
